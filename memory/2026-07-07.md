## 04:20-04:39 CDT — n8n Workflow List UI Blank (FIXED)

**Status:** ✅ COMPLETE — Workflows visible in n8n UI
**Reference:** `memory/2026-07-07-n8n-workflow-list-fix.md`

### Problem
n8n workflow list page (`/workflows`) was blank. Browser console error:
```
TypeError: null is not an object (evaluating 'e.updatedAt.toString')
WorkflowsView.vue:372
```

### Root Cause (3 issues, same symptom)

1. **6 orphaned `shared_workflow` entries** — pointed to deleted workflows, returned NULL `updatedAt` on join
2. **4 SAOS workflows with NULL timestamps** — Chat Bridge, Customer Support, Document Classification, Scheduled Report Generator were inserted via API without `createdAt`/`updatedAt`
3. **7 active workflows missing `workflow_published_version` entries** — API returned null version metadata
4. **93 orphaned `workflow_statistics` + 6 `workflow_history` + 18 `workflow_publish_history`** — pointing to deleted workflows

### Fix Applied

| Fix | Count |
|-----|-------|
| Deleted orphaned `shared_workflow` entries | 6 |
| Set timestamps on 4 SAOS workflows | 4 |
| Created `workflow_published_version` entries | 7 |
| Deleted orphaned `workflow_statistics` | 93 |
| Deleted orphaned `workflow_history` | 6 |
| Deleted orphaned `workflow_publish_history` | 18 |

### Prevention SQL (run after ANY workflow import via API/DB)

See `memory/2026-07-07-n8n-workflow-list-fix.md` for the full prevention SQL block.

### Lesson Learned

The `e.updatedAt.toString()` crash has **multiple possible causes**, not just NULL `updatedAt` in `workflow_entity`. Always check:
1. `workflow_entity` for NULL timestamps
2. Orphaned `shared_workflow` entries
3. Missing `workflow_published_version` for active workflows
4. Orphaned records in `workflow_statistics`, `workflow_history`, `workflow_publish_history`
5. Use `n8n export:workflow --all` to verify what the API actually returns
