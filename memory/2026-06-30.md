## Night Session: Invoice Pipeline Fixed (22:21 CDT)

### Problem
"Systack Private — Invoice Email Pipeline" (Ny4kzzf1bN4NODGn) was active but had **0 executions** — silently failing on every email.

### Root Cause
- Workflow had unnecessary "Code in JavaScript" node that restructured binary data
- "Has PDF Attachment?" node checked `{{ $binary.file.fileName }}` — this field **does not exist** in n8n's resolved email format
- "Call Invoice Parser" used `inputDataFieldName="file"` — also wrong
- Correct format uses: `$binary.attachment_0.fileName` and `inputDataFieldName="attachment_0"`

### Fix Applied
1. Removed unnecessary "Code in JavaScript" node
2. Fixed Has PDF to check `{{ $binary.attachment_0.fileName }}`
3. Fixed Call Invoice Parser to use `inputDataFieldName="attachment_0"`
4. Simplified connections: IMAP → Has PDF → Parser → Email
5. Restarted n8n to apply changes
