# SAOS Client Onboarding Wizard

*Step-by-step wizard for new SAOS clients. Self-guided or Systack-assisted.*

**Version:** 1.0  
**Last Updated:** 2026-07-06  
**Owner:** SOL 🛰️  
**Classification:** Client-Facing

---

## Overview

This wizard guides new SAOS clients through the onboarding process. It can be:
- **Self-guided:** Client completes steps via the portal
- **Systack-assisted:** Green/SOL walks client through each step on a video call

**Typical Duration:** 15-30 minutes (self-guided) or 45-60 minutes (assisted)
**Prerequisites:** Contract signed, payment method on file, VPS provisioned

## Post-Wizard: What Happens Next

### Immediate (Within 1 Hour)
- Client receives confirmation email with portal URL and login instructions
- Temporary PIN generated and sent separately
- SOL creates welcome conversation in portal

### Day 1
- VPS fully provisioned and configured
- Selected services activated
- Test data loaded for validation

### Day 2-3
- Integration testing (email, forms, CRM)
- Dashboard populated with sample data
- Service configuration finalized

### Day 4-7
- Client training session scheduled
- End-to-end testing with real data
- Adjustments based on client feedback

### Day 8-14
- Monitoring and fine-tuning
- Client validation call
- Any issues resolved

### Day 15
- **Go-live:** Production data flow begins
- Monitoring activated
- 30-day check-in scheduled

## Troubleshooting

### Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| "Email integration failed" | Wrong password or IMAP not enabled | Use app password, enable IMAP in email settings |
| "Webhook not receiving" | URL copied incorrectly | Copy exact URL from wizard, no extra spaces |
| "Logo won't upload" | Wrong format or too large | Use PNG/SVG under 2MB, 400x400px minimum |
| "Can't add more users" | Tier limit reached | Upgrade to Enterprise or contact Systack |
| "Service says unavailable" | Dependency not met | Complete required integration step first |

- **In-wizard chat:** Click chat icon in bottom right corner

## Wizard Implementation Notes (Internal)

### Technical Stack
- **Frontend:** HTML + JavaScript (embedded in customer portal)
- **Backend:** Existing `/api/onboarding` endpoints in api.py
- **State:** Saved in `onboarding_sessions` table (not yet created)
- **Progress:** Step completion tracked in localStorage + server

### Database Table Needed

```sql
CREATE TABLE onboarding_sessions (
    id SERIAL PRIMARY KEY,
    client_id INTEGER REFERENCES saos_clients(id),
    current_step INTEGER DEFAULT 1,
    data JSONB DEFAULT '{}',
    status VARCHAR(20) DEFAULT 'in_progress',
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    completed_at TIMESTAMP
);
```

### API Endpoints Needed
- `POST /api/onboarding/start` — Create session
- `GET /api/onboarding/progress` — Get current state
- `POST /api/onboarding/step/{n}` — Save step data
- `POST /api/onboarding/complete` — Final submission
- `POST /api/onboarding/test-email` — Test email integration
- `POST /api/onboarding/test-webhook` — Test webhook endpoint
