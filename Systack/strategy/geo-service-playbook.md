## Audit Scoring Model (v1)

Total: 100 points

| Category | Points | What We Check |
|---|---|---|
| Entity Presence | 20 | Name, address, phone, attorney/principal names consistent across web |
| Authority Score | 20 | Legal directories, BBB, chamber, local press, backlinks |
| Review Score | 20 | Google Reviews, Avvo, Facebook, volume + recency + rating |
| AI Readability | 20 | Schema markup, clear services, FAQ, location pages, bios |
| Recommendation Likelihood | 20 | Manual AI query test: "Best [service] in [city]" |

## Audit Workflow (v1 — AI + Human Review)

1. Lead submits form (Business Name, Website, City, Industry, Email)
2. n8n stores lead + emails Green
3. Claude/SOL performs analysis:
   - Scrape website
   - Check schema markup
   - Check title/meta
   - Check location pages
   - Check attorney/principal bios
   - Check contact info consistency
   - Check review counts
   - Check local directory presence
   - Run AI recommendation queries
4. Generate PDF audit report
5. Send to prospect
6. Green follows up for setup/retainer conversation
